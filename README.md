# DigiSafeHome – IoT-Based Smart Home Automation

## 📌 Overview
DigiSafeHome is an IoT-based smart home automation project designed to improve home safety and convenience. It uses an ESP8266 Wi-Fi module, sensors, and the Blynk platform to monitor environmental conditions, measure water levels, and control electrical appliances remotely.

## ✨ Features
- **Smart Appliance Control:** Remotely control electrical appliances using relay modules and Blynk.
- **Gas Detection:** Monitor gas sensor readings and activate a buzzer when gas is detected.
- **Water Level Monitoring:** Measure water levels using an ultrasonic sensor.
- **Motion Detection:** Detect movement using a PIR sensor.
- **Real-Time Monitoring:** Send sensor readings to the Blynk dashboard over Wi-Fi.
- **Alert System:** Use a buzzer and LEDs for local alerts.

## 🛠️ Technologies Used
- ESP8266 NodeMCU
- Arduino IDE
- Embedded C/C++
- Blynk IoT Platform
- MQ-8 Gas Sensor
- PIR Motion Sensor
- Ultrasonic Sensor
- Relay Modules
- Buzzer and LEDs

## ⚙️ Working Principle
The ESP8266 connects to Wi-Fi and communicates with the Blynk IoT platform. Sensors monitor environmental conditions, while the microcontroller processes readings and controls connected appliances through relay modules.

## 🚀 Setup Instructions
1. Install the Arduino IDE.
2. Install the ESP8266 board package.
3. Install the Blynk library.
4. Connect the sensors and other components according to your circuit design.
5. Configure your Blynk dashboard and authentication token.
6. Add your Wi-Fi credentials securely.
7. Upload the code to the ESP8266.
8. Monitor sensor readings and control appliances through Blynk.
